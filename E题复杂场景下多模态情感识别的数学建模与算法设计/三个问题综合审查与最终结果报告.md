# 三个问题综合审查与最终结果报告

报告日期：2026年9月24日

## 1. 最终路线

三个问题采用“问题1建立可审计的三模态时间轴，问题2完成监督预测与缺失模态测试，问题3复用问题2最优主干并进行后验解释”的路线：

1. 问题1：50个公共时间窗，语音采用真实音频与CTC声学约束，视觉按真实视频帧定位，所有缺失由mask显式表示。
2. 问题2：比较固定baseline、长度感知重采样、自监督GRU融合和残差融合；同时完成严格同接口复训。旧 `residual_fusion.pt` 保留为指标对照，统一编码路线作为合规候选。
3. 问题3：在统一编码数据上训练可解释模型，并使用模态消融和50窗遮挡，输出附件4预测与证据；旧问题3结果保留为历史对照。

### 1.1 `text_bert` 是否强制

赛题没有强制指定 `text_bert`。附件2同时提供 `text` 和 `text_bert` 两种文本输入形式，参赛队可以二选一；强制要求是训练、验证和专项测试保持同一特征版本和同一输入接口。也就是说，不使用 `text_bert` 可以合规，但不能把附件2的预计算 `text` 与附件3临时重建的另一种文本特征混用。

为满足最严格的可审计口径，本次新增统一链路：附件2和附件3均以 `text_bert` token 为输入，使用固定 `distilbert-base-uncased` revision `12040accade4e8a0f71eabdb258fecc2e7e948be`，取最后四层均值为 `(50,768)` 文本特征；音频、视觉统一使用 `aligned_50`。旧主模型的跨接口结果不再作为严格最终结果。

## 2. 问题1审查结论

### 2.1 已完成内容

- 100条样本均完成文本、语音、视觉特征打包；三模态尺寸分别为 `(100,50,768)`、`(100,50,74)`、`(100,50,35)`。
- 公共时间窗起点为0、窗口连续、终点等于媒体时长、窗口正时长比例均为100%。
- 音频有效窗率99.00%，视觉有效窗率99.80%，有声候选窗率86.74%，文本有效窗率58.68%。
- 80条CTC路径通过但未人工验证，18条低置信，2条文本—音频冲突。
- 1629个词段全部越界率0%、正时长率100%、单调率100%、无重叠率100%。

### 2.2 水平判断与不足

当前是“工程可用的声学约束弱/半强对齐”，不是人工金标准词级对齐。没有统一官方的 `word_align cosine similarity` 或官方余弦阈值可以替代人工词边界真值；余弦只能作为表征相似性辅助指标。

真正的gold指标应在人工标注约20条样本后计算 word onset/offset MAE、±10/20/50 ms命中率和词区间IoU。当前报告已明确将这些指标标记为缺失，避免把内部CTC后验误写成对齐准确率。

## 3. 问题2审查结论

### 3.1 验证与测试指标

问题2验证集主模型 `residual_fusion.pt`：

| Accuracy | Macro-F1 | MAE | Pearson |
|---:|---:|---:|---:|
| 0.622253 | 0.610330 | 0.623941 | 0.601396 |

它不是每个单项都最优：固定baseline的回归指标更稳，`regression_weight=1.0`的Accuracy更高；但主模型的Macro-F1最高，分类与回归折中更适合作为问题3主干。

严格统一编码路线的验证结果为：Accuracy `0.619505`、Macro-F1 `0.578397`、MAE `0.632199`、Pearson `0.617068`，最优轮次为4。该路线的Macro-F1低于旧主模型的 `0.610330`，但输入链路完整一致，因而合规性更强；在没有进一步调参或重复实验前，不应把两者指标混称为同一模型结果。

### 3.2 附件3补测

附件3已完成两种版本、两种文本处理模式共120条推理记录：

- 对齐版本30条，未对齐版本30条；
- DistilBERT重建文本特征为主结果；文本全屏蔽为敏感性对照；
- 主模式下对齐版本预测分布为Negative 2、Neutral 6、Positive 22，平均强度0.436542；
- 主模式下未对齐版本预测分布为Negative 2、Neutral 6、Positive 22，平均强度0.464932；
- 附件3无真值，因此不虚构Accuracy、F1、MAE或Pearson。

附件3测试的主要局限是无标签，且文本特征需要从token ID或原始转写重新生成；这已经在输出JSON和报告中显式记录。

统一编码正式候选的附件3结果为30条：Negative 6、Neutral 3、Positive 21，平均预测强度0.185826。该结果仅用于专项推理展示，不含监督指标。

## 4. 问题3审查结论

### 4.1 解释验证指标

统一编码问题3模型在附件2验证集上复核得到：

| 指标 | 数值 |
|---|---:|
| Accuracy | 0.637363 |
| Macro-F1 | 0.601580 |
| MAE | 0.612262 |
| Pearson | 0.629627 |
| 最大影响窗平均置信度下降 | 0.010919 |
| 随机窗平均置信度下降 | 0.001215 |
| Top-Random | 0.009704 |

Top-Random为正，说明遮挡排序能够识别比随机窗口更重要的局部时间证据，但这仍是模型行为解释，不等价于人类因果机制证明。

### 4.2 附件4与视频关键帧

- 附件4使用统一编码问题3模型完成20条无标签推理；
- 输出120条解释证据，每条样本6条；
- 统一编码模型的视觉证据对应29张视频关键帧，均从附件4原始MP4用PyAV解码；
- `q3_aligned_text_bert_final/attachment4/video_keyframe_manifest.csv`记录源视频、窗口、目标时间、实际帧时间、误差和SHA-256。

## 5. 三个问题的剩余风险

| 问题 | 当前不足 | 报告中的处理 |
|---|---|---|
| 问题1 | 没有人工词级gold timestamp | 不宣称词级准确率，给出结构指标并列出gold指标待补 |
| 问题2 | 旧主模型的训练接口与附件3重建接口不完全相同；统一编码路线指标暂低于旧主模型 | 旧结果标为探索性；统一编码结果单独报告，明确附件3无监督指标 |
| 问题3 | 解释是后验遮挡，不是因果证明 | 已切换统一编码checkpoint；报告仍不把遮挡重要性夸大成因果证明 |
