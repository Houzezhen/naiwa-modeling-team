# 问题1最终报告：特征提取与时序对齐

报告日期：2026年9月24日

## 1. 最终结论

问题1完成了100条样本的文本、语音、视觉三模态特征提取，并将三种模态映射到同一条50窗口公共时间轴。当前结果可表述为：

> 可复现的声学约束词级弱/半强对齐，以及音视频公共时间窗对齐。

它已经达到后续问题2、问题3建模所需的工程可用水平，但不能写成“人工标注级精确词级对齐”或“已验证的词边界准确率”。原因是数据没有提供人工词级起止时间戳，CTC后验、语音活动候选和时间合法性检查都不能替代gold timestamp。

## 2. 公共时间轴与三模态特征

对每条实际时长为 `T` 的视频划分50个半开区间：

```text
I_k=[kT/50,(k+1)T/50), k=0,...,49
```

窗口特征采用局部观测与公共时间窗的重叠时长加权平均；没有有效观测时填零并设置对应掩码，避免把缺失误当成真实零值。

| 模态 | 最终形状 | 主要方法 | 时间定位 |
|---|---:|---|---|
| 文本 | `(100,50,768)` | DistilBERT最后4层均值 | Wav2Vec2-CTC词级路径与声学活动候选交集 |
| 语音 | `(100,50,74)` | MFCC、Chroma、频谱、基频、能量等 | 16 kHz单声道音频按公共时间窗统计 |
| 视觉 | `(100,50,35)` | 人脸、外观、纹理、运动特征 | 每窗选择最接近中心的视频帧 |

文本对齐使用赛题提供转写，不重新生成转写。平均CTC后验低于0.50的样本拒绝词级定位；全零音轨或转写与音频冲突时保留其余模态并置文本掩码为0。

## 4. 关于 `word_align` 余弦相似度

没有一个统一官方标准叫“`word_align cosine similarity`”，也没有一个官方余弦阈值可以单独证明词的起止时间对齐正确。

余弦相似度可以用于比较音频和文本表征的语义相似性，但它回答的是“两个向量方向是否相似”，不是“这个词在第几秒开始和结束”。即使文本和音频向量余弦相似度很高，也可能存在整体平移、停顿错配或词边界偏移。因此本项目没有把余弦相似度冒充词级时间对齐准确率。

当前没有人工词级时间戳，所以以下真正具有gold意义的指标暂不能填写：

| gold指标 | 当前状态 |
|---|---|
| word onset MAE | 无人工词起点，暂缺 |
| word offset MAE | 无人工词终点，暂缺 |
| 边界误差在±10 ms内比例 | 暂缺 |
| 边界误差在±20 ms内比例 | 暂缺 |
| 边界误差在±50 ms内比例 | 暂缺 |
| 词区间IoU | 暂缺 |

如果需要把报告升级到“人工验证级”，建议随机抽取约20条样本，人工标注每个词的起止时间，随后计算上述指标。当前的边界合法性、单调性、覆盖率和CTC后验只能作为无gold条件下的内部质量审计。

## 5. 结果等级判断

- 音频—视觉公共时间轴：工程可用，覆盖率分别为99.00%和99.80%。
- 文本—音频定位：有声学约束和CTC路径，优于全文均匀铺开，但80%样本仍是 `unverified`，因此属于弱/半强对齐而非金标准强制对齐。
- 复现与审计：时间窗结构、词段合法性、掩码一致性均通过，适合进入问题2和问题3。
- 论文措辞：建议写“声学约束的弱监督词级对齐”或“CTC辅助的半强制对齐”，不要写“对齐准确率达到100%”。
