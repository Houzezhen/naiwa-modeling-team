# 第三问历史版：基于旧问题2模型的后处理解释

> 本文件保留旧 `residual_fusion.pt` 的解释实验记录。由于旧模型训练与附件3文本重建接口不一致，它不属于当前最终合规主模型。当前正式结果见 `问题3_最终报告_第二问最优模型解释版.md`，最终 checkpoint 为 `q3_aligned_text_bert_final/q3_explainable_best.pt`。

## 1. 版本说明

本版本直接使用第二问验证集选择的 `residual_fusion.pt`，不重新训练第三问预测模型。此前的 `q3_run/` 是“注意力 + 门控”的独立探索版本，本报告以 `q3_q2_best_run_final/` 作为第三问正式结果。

这样处理的理由是：第三问的解释应当解释实际使用的第二问最优预测模型，而不是另训练一个性能不同的替代模型。

### 为什么没有重新训练预测模型

本版本不是遗漏训练，而是采用“冻结第二问主模型 + 后处理解释”的保守方案：

1. 第二问已经在附件2训练集上完成参数学习，并在验证集上选出了 `residual_fusion.pt`；
2. 第三问的附件4没有标签，不能用附件4训练解释层或调整预测参数；
3. 第三问要求解释最终预测依据，若重新训练一个注意力模型，解释的可能是新模型，而不是第二问实际最优模型；
4. 模态消融和时间窗遮挡不引入可学习参数，因此不需要再次训练，也不会改变第二问的预测结果。

因此，本版本的第三问新增内容是一个参数固定的解释模型：它对第二问模型的输入进行模态级和时间窗级干预，根据预测变化输出贡献与证据。

这是一版优先保证路线正确、结果可追溯的第三问基线。如果后续需要“第三问单独训练的内生解释模型”，可以在此版本上增加可学习解释头，但那应作为对照实验，不能替代当前对第二问最优模型的忠实解释。

## 4. 后处理解释方法

不改变第二问模型参数，使用输入遮挡计算模型决策变化。

### 4.1 模态贡献

对每个样本分别屏蔽文本、语音、视觉的全部有效窗口，得到预测类别置信度下降：

```text
Delta_m = p(full) - p(without modality m)
```

将非负的三个 `Delta_m` 归一化，得到：

```text
contribution_m = Delta_m / sum(Delta_m)
```

贡献最大的模态作为主要参考模态。

### 4.2 局部关键证据

对每个模态的50个时间窗逐一遮挡，计算：

```text
Delta_(m,k) = p(full) - p(masked modality m at window k)
```

按 `Delta_(m,k) × contribution_m` 排序，输出Top-K关键证据。这样得到的证据直接来自第二问最终预测模型，而不是注意力权重替代品。

## 5. 解释验证

在附件2验证集随机抽取128条样本，对每个模态比较“最大影响窗口”和随机窗口的置信度下降：

| 指标 | 结果 |
|---|---:|
| 注意力/遮挡最大影响窗口平均下降 | 0.015308 |
| 随机窗口平均下降 | 0.001004 |
| Top - Random | 0.014304 |

这里不称为注意力验证，而称为遮挡证据验证。结果表明，按模型实际输出变化选出的窗口，其影响明显高于随机窗口。

## 6. 附件4专项推理

附件4对齐版本共20条无标签样本，输出：

- 20条情感极性与情感强度预测；
- 每条样本的文本、语音、视觉贡献；
- 每条样本的主要参考模态；
- 每条样本6条关键证据，共120条；
- 视觉证据对应的实际视频时间区间和24张关键帧。

结果文件：

```text
q3_q2_best_run_final/attachment4/q3_predictions.csv
q3_q2_best_run_final/attachment4/q3_explanations.csv
q3_q2_best_run_final/attachment4/evidence_frames/
```

第 `k` 个对齐窗口首先按统一时间轴映射为 `[kT/50,(k+1)T/50)`；视频秒数由 PyAV 读取，CSV同时保留归一化位置和实际秒级位置。

## 7. 第三问结果汇总

第三问在有标签的附件2验证集上，预测结果沿用第二问最优模型，因此预测指标为：

| 第三问输出 | 结果 |
|---|---:|
| 情感极性 Accuracy | 0.622253 |
| 情感极性 Macro-F1 | 0.610330 |
| 情感强度 MAE | 0.623953 |
| 情感强度 Pearson | 0.601379 |
| Top关键窗口平均置信度下降 | 0.015308 |
| 随机窗口平均置信度下降 | 0.001004 |
| 证据区分度 Top-Random | 0.014304 |

前四项是第二问预测主干在第三问中的复核指标，后三项是第三问新增的解释指标。附件4没有真实标签，所以不能报告附件4的 Accuracy、F1、MAE 或 Pearson；附件4只能报告20条预测、模态贡献、关键时间窗和关键帧。

## 8. 数据边界与限制

模型只使用附件2训练阶段已经得到的 checkpoint；附件2验证集仅用于复核和解释方法验证；附件4不参与任何参数或阈值选择。文本没有逐词真实时间戳，因此文本证据片段使用文本词序与50个公共窗口的弱映射；语音和视觉证据可以直接回溯到视频时间轴。
