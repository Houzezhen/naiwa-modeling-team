# 问题3最终报告：基于问题2最优模型的可解释性情感预测

## 一、最终路线

本题第三问采用“问题2最优模型作为预测主干，反事实遮挡作为解释方法”的路线，不重新训练一个与问题2不同的预测模型。

问题2最优 checkpoint 为：

```text
q2_baseline/checkpoints/residual_fusion.pt
```

该模型已经在附件2训练集上完成参数学习，并依据验证集结果完成模型选择。第三问直接解释该模型的真实决策依据，避免出现“问题2模型负责预测、另一个问题3模型负责解释”的模型不一致问题。

## 二、问题2主干结构

| 项目 | 设置 |
|---|---|
| 输入数据 | 附件2 aligned 三模态特征 |
| 时间窗口 | 每个模态50个窗口 |
| 特征维度 | 文本768、语音74、视觉35 |
| 时序编码 | 两层单向GRU，隐藏维度128 |
| 残差旁路 | 各模态 masked mean 与 masked std |
| 输出 | 三分类情感极性 + 连续情感强度 |
| 回归损失权重 | 0.5 |

GRU在本方案中只是问题2已经确定的时序编码器，不作为问题3的创新点。问题3的新增内容是可量化的模态贡献、局部时间证据和反事实验证。

## 三、可解释性方法

### 1. 模态贡献

对同一样本进行四次推理：

- 完整文本、语音、视觉输入；
- 屏蔽文本；
- 屏蔽语音；
- 屏蔽视觉。

对预测类别置信度计算模态消融下降：

```text
Delta_m = p(full) - p(without modality m)
```

将三个非负下降值归一化，得到文本、语音、视觉贡献，最大贡献对应主要参考模态。

### 2. 局部关键证据

对每个模态的50个时间窗口分别进行遮挡：

```text
Delta_(m,k) = p(full) - p(masked modality m at window k)
```

按照 `Delta_(m,k) × modality_contribution_m` 排序，输出每条样本的Top-6证据。第 `k` 个窗口对应统一时间轴区间：

```text
I_k = [kT/50, (k+1)T/50)
```

视觉证据使用 PyAV 从原始视频导出对应关键帧；文本证据使用文本词序与50个窗口进行弱时间映射；语音证据直接记录视频时间区间。

## 四、验证集结果

第三问不改变问题2模型参数，因此前四项是问题2最优主干在第三问中的复核指标；后三项是第三问新增的解释指标。

| 指标 | 结果 |
|---|---:|
| 情感极性 Accuracy | 0.622253 |
| 情感极性 Macro-F1 | 0.610330 |
| 情感强度 MAE | 0.623953 |
| 情感强度 Pearson | 0.601379 |
| 最大影响窗口平均置信度下降 | 0.015308 |
| 随机窗口平均置信度下降 | 0.001004 |
| 证据区分度 Top-Random | 0.014304 |

解释验证从附件2验证集抽取128条样本。最大影响窗口的平均置信度下降明显高于随机窗口，说明遮挡方法能够选出对当前预测更关键的时间证据。

## 五、附件4专项结果

附件4为无标签专项测试集，因此不能计算 Accuracy、F1、MAE 或 Pearson，只输出预测和解释结果：

- 完成20条样本推理；
- 输出20条极性与强度预测；
- 输出每条样本的三模态贡献和主要参考模态；
- 输出120条关键证据，每条样本6条；
- 导出24张视觉关键帧，并进一步生成带实际解码时间和SHA-256的关键帧清单；
- CSV同时记录归一化窗口位置和实际秒级时间区间。
