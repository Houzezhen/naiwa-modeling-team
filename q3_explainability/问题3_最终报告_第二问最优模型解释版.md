# 问题3最终报告：统一编码复杂主模型的可解释性情感预测

## 一、最终路线

本题第三问采用“统一输入接口上的复杂多模态模型 + 反事实遮挡解释”的最终路线。旧 `residual_fusion.pt` 仅作历史指标对照，不作为最终主模型。

最终主模型 checkpoint 为：

```text
q3_explainability/q3_aligned_text_bert_final/q3_explainable_best.pt
```

该模型在统一 `text_bert + aligned_50` 接口上完成训练和验证：文本 token 经固定 revision 的 `distilbert-base-uncased` 取最后四层均值，音频和视觉使用同一组50窗特征，训练、验证及专项推理使用同一编码、mask 和归一化规则。

## 二、最终主模型结构

| 项目 | 设置 |
|---|---|
| 输入数据 | 统一 `text_bert` 编码 + `aligned_50` 三模态特征 |
| 时间窗口 | 每个模态50个公共时间窗口 |
| 特征维度 | 文本768、语音74、视觉35 |
| 时序编码 | 三路独立两层双向 GRU，隐藏维度128 |
| 时间聚合 | 每个模态独立的 masked temporal attention |
| 模态融合 | 样本级 modality gate + 多层融合网络 |
| 输出 | 三分类情感极性 + 连续情感强度 |
| 解释验证 | 模态消融 + 50窗反事实遮挡 |

该结构具有明确的复杂度：同时建模三种模态的时间依赖、模态内部重点窗口、样本级模态权重和分类/回归双任务。它不是简单的拼接或单层 baseline；注意力和门控权重还可直接用于证据解释。

## 三、可解释性方法

### 1. 模态贡献

对同一样本进行四次推理：

- 完整文本、语音、视觉输入；
- 屏蔽文本；
- 屏蔽语音；
- 屏蔽视觉。

对预测类别置信度计算模态消融下降：

```text
Delta_m = p(full) - p(without modality m)
```

将三个非负下降值归一化，得到文本、语音、视觉贡献，最大贡献对应主要参考模态。

### 2. 局部关键证据

对每个模态的50个时间窗口分别进行遮挡：

```text
Delta_(m,k) = p(full) - p(masked modality m at window k)
```

按照 `Delta_(m,k) × modality_contribution_m` 排序，输出每条样本的Top-6证据。第 `k` 个窗口对应统一时间轴区间：

```text
I_k = [kT/50, (k+1)T/50)
```

视觉证据使用 PyAV 从原始视频导出对应关键帧；文本证据使用文本词序与50个窗口进行弱时间映射；语音证据直接记录视频时间区间。

## 四、验证集结果

前四项为最终主模型在附件2验证集上的预测指标，后三项为本题新增的解释验证指标。

| 指标 | 结果 |
|---|---:|
| 情感极性 Accuracy | 0.637363 |
| 情感极性 Macro-F1 | 0.601580 |
| 情感强度 MAE | 0.612262 |
| 情感强度 Pearson | 0.629627 |
| 最大影响窗口平均置信度下降 | 0.010919 |
| 随机窗口平均置信度下降 | 0.001215 |
| 证据区分度 Top-Random | 0.009704 |

在同一验证集上，固定 aligned baseline 的 Accuracy、Macro-F1、MAE、Pearson 分别为 0.612637、0.588115、0.616443、0.624582。因此最终主模型四项指标均超过简单 baseline：Accuracy 提升 0.024726，Macro-F1 提升 0.013465，MAE 降低 0.004181，Pearson 提升 0.005045。该比较只使用附件2验证集，不将附件4无标签结果伪装成监督指标。

解释验证从附件2验证集抽取128条样本。最大影响窗口的平均置信度下降高于随机窗口，说明遮挡方法能够选出对当前预测更关键的时间证据；这属于模型行为解释，不等价于人类因果机制证明。

## 五、附件4专项结果

附件4为无标签专项测试集，因此不能计算 Accuracy、F1、MAE 或 Pearson，只输出预测和解释结果：

- 完成20条样本推理；
- 输出20条极性与强度预测；
- 输出每条样本的三模态贡献和主要参考模态；
- 输出120条关键证据，每条样本6条；
- 导出24张视觉关键帧，并进一步生成带实际解码时间和SHA-256的关键帧清单；
- CSV同时记录归一化窗口位置和实际秒级时间区间。
